# C# Food Order Application

## Overview
A Windows Forms desktop application developed using C# to calculate a food order's total price based on the customer's selections.

## Features
- Enter the customer's name.
- Select a food item from a list.
- Choose a small or large size.
- Add optional cheese and sauce.
- Calculate and display the order details and total price.
- Validate required inputs and display error messages when information is missing.

## Technologies
- C#
- Windows Forms
- .NET Framework
- Visual Studio

## How to Run
1. Open the solution file (`.slnx`) in Visual Studio.
2. Build the project.
3. Run the application.
4. Enter a name, select a food item and size, and optionally choose extra toppings.
5. Click the Add button to display the order details and total price.

## Concepts Practiced
- Event handling
- Conditional statements
- Input validation
- Exception handling (`try-catch`)
- Windows Forms controls

## Purpose
This project was created for practicing C# Windows Forms application development and basic event-driven programming.
